# StudyHub

A Kotlin Multiplatform application for managing study tasks and subjects.

## Features

- **Task Management** — Create, update, and delete study tasks.
- **Subject Tracking** — Organize tasks by subject with custom colors and icons.
- **Calendar View** — Visualize task deadlines on a calendar.
- **Profile** — View study statistics and insights.

## Project Structure

- `composeApp` — Common logic and UI for Android and iOS.
- `iosApp` — iOS specific entry point.

## Technology Stack

- **UI** — Compose Multiplatform
- **DI** — Koin
- **Database** — SQLDelight
- **Network** — Ktor
- **Concurrency** — Kotlin Coroutines & Flow
- **Persistence** — DataStore
